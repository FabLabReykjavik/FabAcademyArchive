# 🧭 Fab Academy Archive

### An archive of the Fab Academy program (2012 – present)

This repository hosts a public, static archive of the **Fab Academy** course content —  
preserving the final state of class materials and assignments from each year since 2012.

The goal is to make the program’s evolution through time easily accessible for reference, study, and inspiration.

---

## 🌐 View the Archive Website

You can browse the complete archive online here:  
👉 **[https://fablabreykjavik.github.io/FabAcademyArchive/](https://fablabreykjavik.github.io/FabAcademyArchive/)**

---

## 📚 About Fab Academy

The [Fab Academy](https://fabacademy.org/) is an internationally distributed educational program  
founded and directed by [Professor Neil Gershenfeld](https://ng.cba.mit.edu/)  
at the [MIT Center for Bits and Atoms (CBA)](https://cba.mit.edu/).

Each year’s archive reflects the state of the course materials as they were  
on the final update of that academic cycle.

If you are interested in joining the program or viewing the current class materials,  
please visit the official sites:

- 🌐 [fabacademy.org](https://fabacademy.org/)
- 🧩 [fabacademy.org/2025](https://fabacademy.org/2025) – the most recent year (not yet archived)

## 🗂️ Repository Structure

| Path | Description |
|------|--------------|
| `docs/years/` | All archived years (2012 – 2024), mirroring the class site structure of each year |
| `docs/classes/` | Overview pages that link each class to its versions across different years |
| `docs/js/` | Client-side scripts that improve media handling and viewing (e.g., in-browser video playback) |
| `docs/assets/` | Icons, stylesheets, and visual assets used by the archive site |

The website is built using **[MkDocs Material](https://squidfunk.github.io/mkdocs-material/)**  
and is hosted via **GitHub Pages**.

---

## 🪣 Related Repository — Assets

Large binary files (images, videos, diagrams, PDFs, etc.) are stored separately  
to keep the main archive light and efficient.

➡️ **Assets Repository:**  
[`FabAcademyArchiveAssets`](https://github.com/FabLabReykjavik/FabAcademyArchiveAssets)

That repository contains all original class materials, organized by year and master copy.
